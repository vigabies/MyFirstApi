# 🚀 MyFirstAPI

Minha primeira API desenvolvida em **C#** utilizando **.NET**.

Este projeto faz parte dos meus estudos em desenvolvimento backend e foi criado para praticar os principais conceitos de criação e estruturação de uma API utilizando ASP.NET Core.

## 💻 Tecnologias

- C#
- .NET
- ASP.NET Core
- Swagger / OpenAPI
- Visual Studio
- Postman

## 📚 Conceitos praticados

- Criação de APIs
- Controllers
- Endpoints
- Requisições HTTP
- Métodos HTTP
- Estrutura de projetos ASP.NET Core
- Swagger / OpenAPI
- Desenvolvimento backend com C#
